## Почему AltFy

AltFy создан для тех, кому нужен быстрый доступ к сетевым инструментам без десятков отдельных окон и сложных ручных настроек. Выберите нужный режим, подключитесь и управляйте всеми компонентами из одного места.

- **Один компактный клиент** для VPN, DPI-инструментов и Telegram-прокси.
- **Гибкая маршрутизация** — от полного туннеля до прокси только для выбранных приложений.
- **Автоматический подбор стратегий** для обхода DPI.
- **Работа в фоне** через системный трей.
- **Полная локализация** интерфейса на русском, английском и китайском языках.

## Возможности

### 🔒 VPN на базе sing-box

Современное ядро **sing-box** обеспечивает работу VPN-подключения и туннельных конфигураций.

Доступны два режима:

- **TUN** — маршрутизация трафика через виртуальный сетевой интерфейс;
- **Системный прокси** — подключение приложений через системные настройки прокси.

### 🎯 Split Tunneling и прокси для приложений

Настройте, какой трафик должен проходить через VPN, а какой — напрямую. AltFy поддерживает **Split Tunneling** и позволяет назначать прокси отдельным приложениям, не меняя сетевое поведение всей системы.

### ⚡ Анти-DPI: Zapret + ByeDPI

Встроенные инструменты **Zapret** и **ByeDPI** помогают обходить DPI-фильтрацию и ограничения доступа.

AltFy умеет автоматически подбирать рабочие стратегии, чтобы не приходилось вручную перебирать параметры и запускать отдельные скрипты.

### ✈️ TG-WS Proxy

**TG-WS Proxy** обеспечивает подключение Telegram через WebSocket и доступен как отдельный инструмент внутри приложения.

### 🖥️ Системный трей

Сворачивайте AltFy в трей, быстро проверяйте состояние подключения и управляйте сервисами, не занимая место на рабочем столе.

### 🌍 Локализация RU / EN / ZH

Интерфейс полностью переведён на:

- 🇷🇺 русский;
- 🇬🇧 английский;
- 🇨🇳 китайский.

## Установка

1. Откройте [страницу релизов AltFy](https://github.com/onique-king/AltFy/releases).
2. Скачайте установщик Windows из последнего релиза — файл `.msi` или `.exe`.
3. Запустите установщик и следуйте инструкциям на экране.
4. Откройте AltFy и выберите нужный режим: VPN, DPI или TG-WS.
5. Добавьте VPN-конфигурацию либо настройте параметры выбранного инструмента.

> При первом запуске может потребоваться загрузка сетевых компонентов. Для установки и обновления ядер необходимо подключение к интернету.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| [sing-box](https://github.com/SagerNet/sing-box) | VPN, TUN и обработка туннельных подключений |
| [Zapret](https://github.com/Flowseal/zapret-discord-youtube) | Обход DPI-фильтрации |
| [ByeDPI](https://github.com/hufrea/byedpi) | Альтернативные стратегии обхода DPI |
| TG-WS Proxy | Подключение Telegram через WebSocket |

AltFy показывает состояние компонентов и позволяет обновлять необходимые ядра прямо из приложения.

## Для разработчиков

Проект построен на современных open-source технологиях:

- [Tauri 2](https://tauri.app/) — лёгкая оболочка и системная интеграция;
- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) — интерфейс;
- [Tailwind CSS](https://tailwindcss.com/) — стилизация;
- Rust — нативная часть приложения и управление сетевыми процессами.

Исходный код доступен на [GitHub](https://github.com/onique-king/AltFy). Предложения, pull request’ы и сообщения об ошибках приветствуются.
